# Omasheet 0.1.11

Fixes to the macOS installer and the Windows font, with exact powers and sequences, and the built-in constants shown in the app.

## Install or update

On macOS (Apple silicon or Intel) and on Omarchy and Arch Linux (x86_64 or aarch64):

```sh
curl -fsSL https://raw.githubusercontent.com/librasteve/omasheet/main/install.sh | bash
```

On Windows (64-bit), in PowerShell:

```powershell
irm https://raw.githubusercontent.com/librasteve/omasheet/main/install.ps1 | iex
```

## Fixes

- **macOS installer.** On a Mac whose own `sha256sum` has no `--check`, the installer stopped at "not what SHA256SUMS says it should be" and installed nothing. It now uses `shasum`.
- **Windows font.** The grid used the family name `monospace`, which Windows does not know and may fill with a symbol face. It now uses Consolas, as macOS uses Menlo.
- `5 kg` stays an error; only a name or a call beside a number makes a product.

## Exact numbers

- A power of whole numbers is an exact `Fraction`: `10 ** 100` is not rounded and `10 ** -2` is `1/100`.
- A sequence seeded with whole numbers and fractions steps exactly: `1, 1/3` goes down by `2/3`, not by `0.667`.
- `1/1` joins with `1` as a `Fraction` in the table of type joins in `docs/format.md`.

## In the app

- The built-in constants every file has, such as `pi`, are listed after the file's own, greyed. A constant of the same name in the file replaces one, and a built-in cannot be edited or deleted.
