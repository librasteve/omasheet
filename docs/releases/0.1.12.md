# Omasheet 0.1.12

Windows fixes: the symbols in the app show correctly, there is no console window beside it, and it has the Omasheet icon. There is also a new built-in constant, `i`, and a unit may follow a constant.

## Install or update

On macOS (Apple silicon or Intel) and on Omarchy and Arch Linux (x86_64 or aarch64):

```sh
curl -fsSL https://raw.githubusercontent.com/librasteve/omasheet/main/install.sh | bash
```

On Windows (64-bit), in PowerShell:

```powershell
irm https://raw.githubusercontent.com/librasteve/omasheet/main/install.ps1 | iex
```

## Windows

- **Symbols.** Symbols such as `▾` in the column headers and the status bar came out as `â–¾`: the compiler read the app's text in the system code page. It now reads it as UTF-8.
- **No console window.** The app no longer starts a terminal beside it. Run from PowerShell or cmd, the `omasheet` command still prints there, though the prompt may return before its output appears.
- **Icon.** The executable, the Start menu shortcut, `.omx` files and the Apps & features entry show the Omasheet icon, not the Windows default.

## Expressions

- **`i`** is a built-in constant, the imaginary unit: `3 + 4 * i` is the complex number `3+4i`.
- **A unit after a constant** multiplies the whole term before it: `pi/2 rad` is 1.571 rad, shown to three places, and `pi rad =~= 180°`. A compound unit works too, as `tau rad.s^-1`. A number and a unit still need to be written together, so `5 kg` stays an error.

## The agent skill

The Omasheet skill for Claude Code, `skill/omasheet/SKILL.md`, is part of the package and on `main`, where the README's link to it resolves. It is installed to `/usr/share/omasheet/agent-skill/omasheet/`, and the package prints the command that links it into Claude Code.
