# Omasheet 0.1.9

Omasheet now installs on macOS and Windows as well as Omarchy and Arch Linux, and `Boolean` columns get formats and logic functions.

## Install or update

On macOS (Apple silicon or Intel) and on Omarchy and Arch Linux (x86_64 or aarch64):

```sh
curl -fsSL https://raw.githubusercontent.com/librasteve/omasheet/main/install.sh | bash
```

On Windows (64-bit), in PowerShell:

```powershell
irm https://raw.githubusercontent.com/librasteve/omasheet/main/install.ps1 | iex
```

The macOS app and the Windows build are not code-signed. The installers fetch them in a way that avoids the Gatekeeper and SmartScreen warnings; a zip downloaded by hand will show them.

## Installers

- **macOS.** `Omasheet.app` goes into `/Applications` and the `omasheet` command is linked into `/usr/local/bin`. The app carries its own Qt.
- **Windows.** Installs to `%LOCALAPPDATA%\Programs\Omasheet` with no administrator rights, adds a Start menu entry, opens `.omx` files, puts `omasheet` on your PATH, and lists itself in Apps & features with an uninstaller.
- **Releases** now attach the macOS (arm64 and x86_64) and Windows zips beside the Arch packages, all checksummed and attested.

## Booleans

- `Boolean` columns take display formats, including symbol formats, and there are logic functions and gate operators. See `examples/booleans.omx` and `docs/omx.md`.
- Booleans are set right in the grid.

## In the app

- Paste format and the column caret fixes.

## Also

- README and `docs/` brought up to date, including the type hierarchy.

## Known issues

- The Windows build and installer, and the Intel macOS build, have not been run on those systems before this release.
- Double-clicking an `.omx` in Finder may not open it; `omasheet file.omx` does.
